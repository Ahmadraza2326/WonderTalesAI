# WonderTales Development Rules

## Rule 1

Premium over quantity.

---

## Rule 2

Never duplicate logic.

---

## Rule 3

One service = One responsibility.

---

## Rule 4

Every feature must support the main storytelling pipeline.

---

## Rule 5

Every feature must pass the Disney Test.

Question:

"Does this make WonderTales more magical?"

If not,

do not build it.

---

## Rule 6

Always prefer maintainability.

---

## Rule 7

Never add complexity without measurable benefit.

---

## Rule 8

Build using free infrastructure whenever possible.

Upgrade only when revenue justifies it.

---

## Rule 9

Children always come before technology.

Technology exists to improve the experience.

---

## Rule 10

WonderTales is not an AI tool.

WonderTales is an emotional storytelling experience.

# WonderTalesAI Documentation

This folder contains the core documentation for the WonderTalesAI platform. It is intended to help contributors understand the product vision, the current system design, the project structure, and the planned roadmap.

## Documentation Map

- [Architecture Overview](architecture/system-overview.md) — explains the main product flow and the core AI systems behind story generation.
- [Folder Structure](architecture/folder-structure.md) — describes the current repository layout and the role of each major folder.
- [Roadmap v1](roadmap/roadmap-v1.md) — outlines completed milestones and upcoming work for Version 1.
- [ADR-001: Provider Abstraction](adr/ADR-001-provider-abstraction.md) — documents the architectural decision to abstract AI providers.

## Product Summary

WonderTalesAI is an AI-powered storytelling platform for parents and teachers who want to create safe, educational, and personalized stories for children. The system combines story generation, illustration prompts, narration, and story-reading experiences into a unified workflow.

## Documentation Principles

- Keep documentation aligned with the current implementation.
- Favor clear, product-focused explanations over implementation detail.
- Use diagrams when they make system behavior easier to understand.
- Treat documentation as a living part of the product foundation.

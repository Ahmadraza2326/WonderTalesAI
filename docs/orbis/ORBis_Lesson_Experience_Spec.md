# ORBis Lesson Experience Specification

> **Standard:** Production-Grade Cinematic Learning Stage  
> **Rule:** Lessons are interactive productions, NOT linear text slideshows.

---

## 1. The 5-Scene Lesson Anatomy

Every canonical lesson contains exactly 5 progressive scenes:

```
[ Scene 1: Welcome Hook ]
       │  • Story anchor & real-world wonder
       │  • Guide character introduction & emotional connection
       ▼
[ Scene 2: Direct Visual Demonstration ]
       │  • Concept transformation (groups ➔ array, sound ➔ phoneme wave)
       │  • Synchronized guide narration & signaling highlights
       ▼
[ Scene 3: Guided Physical Manipulation ]
       │  • Child directly interacts with tactile virtual manipulative
       │  • Goal-oriented discovery (e.g. build 3 rows of 4)
       ▼
[ Scene 4: Micro-Question & Diagnostic Scaffolding ]
       │  • Concrete-to-symbolic transfer check
       │  • 4-tier anti-leak misconception feedback
       ▼
[ Scene 5: Reflection Summary & Capstone Launch ]
          • Key takeaway crystallization
          • Reward settlement & seamless portal to flagship game
```

---

## 2. The 4-Tier Diagnostic Scaffolding Engine

When a child encounters a micro-question check in Scene 4:

```
┌─────────────────────────────────────────────────────────────┐
│ Level 1: Attention Cue (Spotlight / Visual Focus)           │
│ "Look closely at the horizontal rows!"                     │
├─────────────────────────────────────────────────────────────┤
│ Level 2: Concept Reminder (Rule / Mental Model)             │
│ "Each row has 4 star gems. There are 3 rows in total."     │
├─────────────────────────────────────────────────────────────┤
│ Level 3: Partial Setup (Equation / Model Framing)           │
│ "3 rows of 4 means: 4 + 4 + 4 = [ ? ]"                     │
├─────────────────────────────────────────────────────────────┤
│ Level 4: Worked Demonstration & Reteach                     │
│ Guide physically counts the array with illuminated markers  │
└─────────────────────────────────────────────────────────────┘
```

**Anti-Leak Defense:** Scaffolding levels never reveal the verbatim answer letter or choice index directly. They illuminate the reasoning path so the final insight is authentically achieved by the child.

## 2. Deep Dive: `magic_machine` (Array Multiplication Capstone)

In *Magic Machine Lab*, multiplication is the direct engine:
* The machine has input gears (Rows) and output flywheels (Columns).
* A level requires producing $12\text{ energy units}$ to power a stargate.
* The child adjusts the array matrix $(3 \text{ rows} \times 4 \text{ slots})$.
* When activated, 3 pistons strike 4 times each in rapid rhythm ($4 \dots 8 \dots 12$), visibly rotating the main turbine into full glow and unlocking the gate.
* If an incorrect array is set (e.g. $2 \times 5 = 10$), the energy gauge fills to 10 and vibrates gently, indicating 2 more energy units are needed.

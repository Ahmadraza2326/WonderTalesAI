# CODING RULES

Use:

- TypeScript
- React
- Vite

Always:

- Keep files small.
- Prefer composition.
- Avoid duplicate code.
- Avoid long functions.
- Use meaningful names.
- Reuse existing services.

Never:

- break StoryOrchestrator
- duplicate services
- duplicate interfaces
- ignore existing types

Build after every feature.

The project must always compile.
